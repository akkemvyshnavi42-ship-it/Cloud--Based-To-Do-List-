# ☁️ Cloud-Based To-Do List

## 📌 Project Description
Cloud-Based To-Do List is a simple and user-friendly web application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks by adding, completing, and deleting tasks through an attractive interface.

## 🎯 Objectives
- To manage daily tasks easily.
- To add and delete tasks.
- To mark tasks as completed.
- To display total and completed task counts.
- To provide a simple and responsive user interface.

## ✨ Features
- ➕ Add new tasks.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks.
- 📊 Display total and completed tasks.
- 📱 Responsive design for mobile and desktop.
- 🎨 Simple and attractive user interface.

## 🛠️ Technologies Used
- **HTML5** – Structures the web page.
- **CSS3** – Designs the interface and layout.
- **JavaScript** – Handles task management and user interactions.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click the file and select **Open with Live Server**, or open it directly in your browser.
5. Start adding, completing, and deleting tasks.

## ⚙️ How It Works

1. Enter a task in the input box.
2. Click the **Add Task** button.
3. Mark a task as completed using its checkbox.
4. Click **Delete** to remove a task.
5. View the total number of tasks and completed tasks.

## ☁️ Cloud Computing Scope

This project demonstrates the front-end functionality of a task management application. The current version stores tasks temporarily in JavaScript memory.

Integration with a cloud database such as Firebase can be added to store tasks online and retrieve them after refreshing the page.

## 🔮 Future Enhancements

- Integrate Firebase for cloud data storage.
- Add user registration and login.
- Synchronize tasks across devices.
- Add task deadlines and reminders.
- Allow users to edit existing tasks.
